PART 2 - MCP JSON-RPC MESSAGE LIFECYCLE
============================================================

Main files:
- mcp_client.py
- mcp_server.py

Important notes:
- MCP is implemented with normal Python dictionaries.
- No network transport is required.
- No MCP SDK is used.
- Required methods are initialize, tools/list, and tools/call.
- Every request has jsonrpc, id, method, and params.
- Every response has the same id plus result or error.

Run a complete lifecycle:

python -c "import json; from mcp_client import MCPClient; c=MCPClient(); c.list_tools(); c.call_tool('get_weather', {'airport':'HYD'}); print(json.dumps(c.trace, indent=2))"

Expected request order:

initialize -> tools/list -> tools/call
